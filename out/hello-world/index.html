Welcome to the new home of my writing.

This site is built with a simple markdown-based system: drop a .md file into the posts/ folder, run npm run build, and publish the generated out/ directory. No CMS, no database, no build complexity—just files.

Why markdown?

Writing in markdown keeps the focus on the words. The site design is a close match to amasad.me: clean typography, a narrow essay column, code blocks, and an RSS feed.

Here's a code sample:

function greet(name) {
  return `Hello, ${name}`;
}

console.log(greet('Asim'));

And a list of things I care about:

  • Software that empowers people
  • Clear, honest writing
  • Minimal tooling that gets out of the way

Publish new essays by adding a markdown file and rebuilding. That's the whole system.
